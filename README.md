# Cafe Soft - Kafe & Restoran POS Yönetim Sistemi

![Private Repository](https://img.shields.io/badge/Status-Private-blue)
![Platform](https://img.shields.io/badge/Platform-DOTNET-orange)
![Maintained](https://img.shields.io/badge/Maintained-Yes-green)

.NET C# WinForms kafe, restoran adisyon ve masa yönetim sistemi.

---

## 🚀 Özellikler (Features)

- Masa yönetimi ve gerçek zamanlı masa durumu takibi
- Adisyon ve sipariş oluşturma, düzenleme ve kapatma
- Kategori bazlı menü ve ürün yönetimi
- Günlük ciro, kasa ve satış raporlamaları
- Kullanıcı dostu dokunmatik ekran uyumlu masaüstü arayüzü

---

## 🛠️ Teknoloji Yığını (Tech Stack)

- **Platform / Mimari:** C#, .NET Framework, Windows Forms, SQL Server / LocalDB
- **Sürüm Kontrolü:** Git & GitHub

---

## 💻 Kurulum ve Çalıştırma (Getting Started)

Projeyi yerel ortamınızda ayağa kaldırmak için aşağıdaki adımları izleyebilirsiniz:

```bash
# Projeyi klonlayın
git clone https://github.com/ahmetokan0101/cafe-soft.git

# Proje dizinine gidin
cd cafe-soft

# Bağımlılıkları yükleyin ve çalıştırın
Visual Studio ile Cafe_Soft.sln dosyasını açıp F5 ile derleyip çalıştırabilirsiniz.
```
